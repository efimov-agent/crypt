# Product: Crypt — a Kiro-ready .NET 10 skeleton

Crypt is a `dotnet new` template for small business web apps, built for the Kiroween "Skeleton Crew" category.
The template ships with its own `.kiro` folder (steering, hooks, custom agents, specs), so a new project starts
Kiro-ready on day one.

Two distinct apps are generated from the same skeleton and live in this repo:
- `apps/haunted-inventory` — stock tracking for a costume/prop rental shop (items, rentals, overdue "haunting" alerts).
- `apps/seance-scheduler` — booking of time slots for sessions with hosts (hosts, slots, bookings, no double booking).

Theme: Halloween, tasteful. Dark UI, readable, accessible (WCAG AA contrast). Spooky naming in UI copy only,
never in code identifiers beyond the app names.
